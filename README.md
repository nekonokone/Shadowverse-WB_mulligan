# Shadowverse WB マリガントラッカー

「Shadowverse: Worlds Beyond」の初期手札とマリガンを記録し、カードごとの統計を確認するWindows用アプリです。

## インストール

1. GitHubの **Releases** を開き、最新リリースの **Assets** から `Shadowverse-WB-Mulligan-Tracker-Setup.exe` をダウンロードします。
2. ダウンロードしたインストーラーを実行し、画面の案内に従います。
3. インストール後、「シャドウバース WB マリガントラッカー」を起動します。

Windows SmartScreenが発行元を確認できないと表示することがあります。これはコード署名証明書を使っていないためです。配布元とファイル名を確認してから実行してください。

## はじめに

### 1. カードと見本画像を登録
「カード登録」タブでカード名を手入力するか、カード名を1列目にしたCSVを読み込みます。ゲーム画面にカードを表示し、一覧からカードを選んで「選択カードの見本画像を登録」を押します。表示された画面上でカード1枚全体をドラッグして囲みます。認識したいカードごとに見本画像を登録してください。

### 2. 対戦を記録
「対戦を記録」タブでデッキ名と先攻・後攻を選び、「画面から4枚を読み取る」を押します。画面に表示された選択用画像上で初期手札4枚を横一列に囲み、読み取り結果を確認・修正します。交換するカードにチェックを入れた後、引き直し後の手札を読み取って、結果を確認してから保存します。選択用画面はEscキーでキャンセルできます。

### 3. 統計と履歴
- 「カード別統計」では全デッキまたは選択したデッキの集計を確認できます。
- 「対戦履歴」では保存済みの対戦を確認し、選択した記録を削除できます。
初手・引き直し後のカード名が違っていたら、統計がずれるので保存前に必ず確認してください。画像認識は登録した見本との照合で行い、OCRは使いません。

## 保存データ
対戦記録と見本画像はPC内の `%APPDATA%\ShadowverseMulliganTracker` に保存されます。GitHubにはプレイ記録や見本画像を含めず、必要な場合はこのフォルダーを自分でバックアップしてください。

## 開発・ビルド
インストーラーの作成にはWindows、Python 3.14、必要なPythonライブラリ、Inno Setup 6または7が必要です。`Install-Dependencies.ps1` で依存ライブラリを準備し、`インストーラを作る.bat` を実行します。完成したインストーラーは `installer-output` に出力されます。
